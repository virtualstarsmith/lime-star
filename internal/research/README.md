# internal/research — 研究

本目录是研究事实源：记录对外部产品、协议和工程范式的调查结论，供需求和路线图引用。边界与目录归属以 `../aiprompts/architecture.md` 为准；本页只定义研究层的用法。

## 硬规则

1. 只写自己核对过的结论。每份研究开头写核对日期和读过的来源路径；没核对过的内容标"未核实"。
2. 不复制外部原文。lime 是 GPL-3.0 项目，对它的内容只能按本仓库语境改写并注明来源路径（根 AGENTS.md 事实源第 8 条）。
3. 研究结论不是规则。要让结论生效，去改 `../aiprompts/` 下的规则文档，或立执行计划。
4. 外部仓库会变。引用本目录的结论前先看核对日期；结论过期就更新或删除。

## 一份研究写什么

- 问题：这次要弄清什么。
- 方法：读了什么、怎么比的、有哪些没查到。
- 结论：按问题逐条回答，事实与判断分开写。
- 启示：对本仓库意味着什么。启示是候选，不自动变成任务。
