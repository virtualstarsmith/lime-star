# Agent 实践需求

> 状态：草稿，待仓库所有者确认。
> 来源：由根 README.md 的项目说明和 `../roadmap/agent-practice.md` 各阶段的退出条件归纳，没有新增范围。

## 场景

开发者在自己的项目目录里通过命令行使用 Agent，让它读写文件、运行命令并报告结果。

## 目标

1. 带着项目目录读写文件。
2. 执行命令。
3. 危险操作先经开发者批准；被拒绝时不执行，并留下可查的记录。
4. 会话中断后可以恢复并继续。

## 功能需求

编号供计划和测试引用；"阶段"是路线图里承诺交付该需求的阶段。

| 编号 | 需求 | 阶段 |
| --- | --- | --- |
| R1 | 命令能安装并启动，输出版本号 | P0 |
| R2 | 与真实模型连续对话至少三轮，模型记得前面的内容 | P1 |
| R3 | 每次模型请求在请求日志里留下一条可关联的记录，不含提示内容和密钥 | P1 |
| R4 | 密钥只从环境变量或 .env 读取，.env 不进入版本库 | P1 |
| R5 | 能读取工作目录里的文件 | P2 |
| R6 | 会话只有一份记录，模型的每次响应和每次工具结果都按发生顺序写进去 | P3 |
| R7 | 能写文件、执行命令；两者是危险操作，执行前出现批准提示，被拒绝后不执行并留下记录 | P4 |
| R8 | 文件路径限定在工作目录内，越界访问被拒绝 | P4 |
| R9 | 进程退出或被中断后，能在新进程里恢复同一个会话并继续；回合进行中被中断也算 | P5 |
| R10 | 能从会话记录导出一次会话的证据包，含时间线、工具与命令结果、警告和真实发生过的验证记录 | P6 |
| R11 | 一次真实失败能提升为仓库内可重放的样本；评测能对固定样本产出摘要 | P6 |

MVP 在 P4 达成，即 R1 到 R8。

## 成功标准（MVP）

- 开发者在命令行里让它新建一个脚本、运行脚本、报告结果，整件事真实发生。
- 写文件和执行命令被标为危险操作，执行前出现批准提示；拒绝后不执行。
- 文件路径限定在工作目录内，越界访问被拒绝。

## 不做的事

以下三项是路线图 P7 的可选扩展，不属于本需求的范围；是否做由仓库所有者在 P7 另立计划时决定：

- 终端全屏界面（TUI）。
- 多模型路由与子 Agent。
- 首个 release。

## 约束

- 产品代码用 Python（uv 管理，3.11 及以上）；治理脚本是零依赖的 Node。
- 模型走 OpenAI 兼容接口。
- 当前验收平台是 Windows。
