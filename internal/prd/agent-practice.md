## 问题与目标

开发者在自己的项目目录里通过命令行使用 Agent，让它读写文件、运行命令并报告结果。lime-star 要交付的最小 Agent 满足四点：

1. 带着项目目录读写文件。
2. 执行命令。
3. 危险操作先经开发者批准；被拒绝时不执行，并留下可查的记录。
4. 会话中断后可以恢复并继续。

这也是一次练习：全程按本仓库的范式交付，每条需求都有可核对的证据。

## 主场景（MVP）

开发者在空目录里启动 `lime-star`，输入："新建一个脚本 hello.py，打印 hello，然后运行它，把结果告诉我。"

1. 终端显示 Agent 浏览或读取目录的动作。
2. Agent 请求写入 hello.py；终端出现批准提示，显示完整内容。开发者输入 y。
3. Agent 请求运行脚本；终端出现批准提示，显示原样命令。开发者输入 y。
4. 终端显示命令输出；Agent 给出最终回复，说明做了什么、结果如何。
5. 开发者换个文件再试一次，在批准提示处输入 n：文件没有被写入，Agent 的回复没有把这件事说成已完成。

## 成功标准

- SC-1 MVP 成立：主场景在真实 CLI 进程里完整发生，开发者至少拒绝一次且拒绝生效。
- SC-2 覆盖：P4 结束时，MVP 范围内每条需求至少有一个场景对应到测试或冒烟断言。
- SC-3 可恢复：P5 结束时，回合进行中被 Ctrl+C 打断后，新进程能恢复并继续对话。
- SC-4 不泄漏：请求日志、证据包和终端输出里搜不到密钥。

### 不做

| 不做的事 | 原因 |
| --- | --- |
| 命令沙箱 | 路径边界管不到任意命令；MVP 以审批作为命令的唯一安全边界（R8.4） |
| 会话级放行、权限配置文件 | 安全边界会依赖会话状态或配置；MVP 只做逐次批准（D-21） |
| 上下文压缩 | 超出模型上下文时按出错处理（R12.4） |
| 成本或 token 预算 | 只记录用量（R3.1），不设上限 |
| 内容搜索工具 | 需要时通过 run_command 进行；只读的列目录已在 MVP 内（D-27） |
| 按 ID 恢复、会话选择界面 | MVP 之后也只恢复最近一个会话（R9.1） |
| 敏感信息脱敏 | 会话记录可能含被读取文件的内容，见"已知边界" |
| 一次性非交互模式 | 冒烟和脚本都通过标准输入驱动交互会话 |
| 终端全屏界面、多模型路由、子 Agent、首个 release | 路线图 P7 的可选扩展，做不做由仓库所有者届时决定 |

## 术语

| 术语 | 含义 |
| --- | --- |
| 工作目录 | 启动 `lime-star` 时所在的目录。路径边界、命令执行和会话归属都以它为准 |
| 会话 | 一次持续的对话，属于一个工作目录，包含多个回合 |
| 回合 | 用户提交一条消息，到 Agent 给出最终回复之间的全过程 |
| 步 | 回合内的一次模型请求及其后的工具执行 |
| 项 | 会话记录里的一行：用户消息、模型文本、推理、工具调用、工具结果、批准、回合开始或回合结局 |
| 会话记录 | 一个会话的全部项，按发生顺序追加，是会话的唯一事实源 |
| 工具 | Agent 能调用的一个能力：read_file、list_dir、write_file、run_command |
| 危险操作 | 会改动文件或执行命令的工具调用，即 write_file 和 run_command |
| 批准 | 用户对一次危险操作的回应，只有批准和拒绝两种 |
| 请求日志 | 每次模型请求一条的可关联记录，不含内容 |
| 证据包 | 从一份会话记录导出的派生物，只读 |
| 回放样本 | 从一次真实运行录下的固定输入与期望，供测试和评测使用 |

## 全局约束

- 平台：Windows 是验收环境。路径处理必须正确对待盘符、反斜杠和大小写不敏感。其他平台未验证，未验证的部分在阶段计划里写明原因。
- 编码：终端输出和写出的文件都是 UTF-8，经管道或重定向读取时也不乱码。
- 安全默认：情况不明时拒绝。未知参数、缺失配置、越界路径、看不懂的批准输入，都不得放行。
- 不用替身：正式命令没有回放或替身开关，回放夹具只在测试里使用（R11.6）。
- 可测试：每条需求的场景都能写成自动化测试或冒烟断言；回合循环的测试不联网（R12.1）。

## 已知边界

- 会话记录包含 Agent 读到的文件内容和命令输出，可能带敏感信息。产品不对这些内容脱敏，也不替用户把 `.lime-star/` 加进忽略列表（位置见 D-29）。
- run_command 能做命令行能做的任何事，路径边界对它无效，唯一的安全边界是审批。
- Agent 的行为（R14）由系统指令约束，只能通过会话记录和评测观察，程序不能保证。
